Die Karte kann nicht geladen werden

Die Seite ist geöffnet, kommt aber an keinen Kartenserver heran. Meistens liegt das daran, dass sie in einer Vorschau geöffnet ist (z. B. in der Claude-App oder einem Mail-/Datei-Viewer). Solche Vorschauen sperren Internetzugriffe.

So klappt es: Datei herunterladen, im Ordner „Downloads“ mit Rechtsklick → „Öffnen mit“ → Chrome, Firefox oder Edge öffnen. Außerdem muss das Internet verbunden sein.
